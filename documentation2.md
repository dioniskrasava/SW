## Часть 1: Обзор проекта и архитектура

### 1.1 Назначение и возможности

**Умный секундомер** - это десктопное приложение, сочетающее функции классического секундомера с системой трекинга активностей.

#### Основные возможности:
- ⏱️ **Базовый секундомер** - точный отсчет времени с миллисекундной точностью
- 🎯 **Два режима работы**:
    - Простой режим (по умолчанию) - только секундомер
    - Расширенный режим - с трекингом активностей
- 📊 **Система активностей** - создание, редактирование, цветовое кодирование задач
- 📝 **Детальная история** - автоматическое логирование всех действий
- ⏸️ **Учет времени пауз** - подсчет периодов бездействия
- 💾 **Локальное хранение** - сохранение данных между сессиями

### 1.2 Технологический стек

- **Язык**: Kotlin 1.9.0
- **UI Framework**: Compose Desktop 1.5.0
- **Асинхронность**: Kotlin Coroutines 1.7.3
- **Сериализация**: Kotlinx Serialization JSON
- **Сборка**: Gradle с Kotlin DSL
- **Целевая платформа**: JVM (Java 17+)
- **Форматы дистрибуции**: AppImage, DEB (Linux)

### 1.3 Архитектурные принципы

Проект следует принципам **чистой архитектуры** с четким разделением ответственности:

```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│     UI Layer    │ ←→ │  Domain Layer    │ ←→ │   Data Layer    │
│                 │    │ (Business Logic) │    │                 │
│ - Composable    │    │ - State Managers │    │ - Repositories  │
│ - Screens       │    │ - Use Cases      │    │ - Models        │
│ - Components    │    │ - Interfaces     │    │ - Serialization │
└─────────────────┘    └──────────────────┘    └─────────────────┘
```

#### Ключевые паттерны:
- **State Hoisting** - поднятие состояния к ближайшему общему предку
- **Repository Pattern** - абстракция доступа к данным
- **Composition over Inheritance** - предпочтение композиции в UI

## Часть 2: Модели данных и бизнес-логика

### 2.1 Модели данных

#### Activity (Активность)
```kotlin
data class Activity(
    val id: String,          // Уникальный идентификатор
    var name: String,        // Название активности
    val color: String,       // HEX-цвет для визуального различия
    var isActive: Boolean = true  // Флаг активности
)
```

#### TimeRecord (Запись времени)
```kotlin
data class TimeRecord(
    val id: String,          // Уникальный идентификатор
    val activityId: String,  // ID связанной активности
    val activityName: String, // Имя активности на момент создания
    val startTime: Long,     // Время начала (мс)
    val endTime: Long,       // Время окончания (мс)
    val duration: Long,      // Продолжительность (мс)
    val type: RecordType     // Тип записи
)
```

#### RecordType (Типы записей)
```kotlin
enum class RecordType {
    START,       // Начало активности
    PAUSE,       // Пауза
    RESET,       // Сброс
    CONTINUE,    // Продолжение после паузы
    COMPLETE,    // Завершение активности
    INACTIVE     // Период бездействия
}
```

#### AppSettings (Настройки)
```kotlin
data class AppSettings(
    val isActivityTrackingEnabled: Boolean = false,  // Включен ли трекинг
    val showLogsInMainScreen: Boolean = true         // Показывать логи на главном экране
)
```

### 2.2 Управление состоянием

#### StopwatchState Interface
```kotlin
interface StopwatchState {
    val isRunning: Boolean                    // Запущен ли секундомер
    val displayTime: Long                     // Текущее отображаемое время
    val selectedActivityId: String?           // Выбранная активность
    val activityLogs: List<TimeRecord>        // История записей
    val isActivityTrackingEnabled: Boolean    // Включен ли трекинг активностей
    val inactiveTime: Long                    // Общее время пауз
    
    fun start()                              // Запуск секундомера
    fun pause()                             // Пауза
    fun reset()                             // Сброс
    fun setSelectedActivity(activityId: String?)  // Выбор активности
    fun clearLogs()                         // Очистка истории
    fun setActivityTrackingEnabled(enabled: Boolean)  // Включение/выключение трекинга
}
```

#### Ключевые особенности:
- **Автоматическое логирование** - все действия автоматически сохраняются
- **Учет времени пауз** - подсчитывается общее время бездействия
- **Сохранение контекста** - при смене активности сохраняется история предыдущей
- **Интеграция с репозиторием** - автоматическое сохранение в JSON

### 2.3 Работа с данными

#### ActivityRepository
Центральный класс для работы с данными:

```kotlin
class ActivityRepository {

    fun saveSettings(settings: AppSettings)

}
```

## Часть 3: Пользовательский интерфейс

### 3.1 Навигация и экраны

#### Система навигации
```kotlin
sealed class AppScreen {
    object Main : AppScreen()      // Главный экран
    object Settings : AppScreen()  // Экран настроек
}
```

#### Главный экран (StopwatchScreen)
- **Таймер** - центральное отображение времени
- **Кнопки управления** - Start, Pause, Reset
- **Выбор активности** - появляется при включенном трекинге
- **История логов** - прокручиваемый список всех событий

#### Экран настроек (SettingsScreen)
- **Вкладка "Основные"**:
    - Чекбокс включения трекинга активностей
    - Описание функциональности
- **Вкладка "Активности"**:
    - Список существующих активностей
    - Кнопка добавления новой активности
    - Редактирование и удаление существующих

### 3.2 Компоненты интерфейса

#### StopwatchButton
Кастомная кнопка с предустановленными стилями:
- Темный фон в активном состоянии
- Оранжевый фон в неактивном состоянии
- Единый стиль для всех кнопок управления

#### ActivityLogs
Компонент отображения истории:
- Прокручиваемый список всех записей
- Цветовое кодирование типов событий
- Форматированное отображение времени
- Поддержка различных типов записей

#### ActivityEditor
Диалоговое окно создания/редактирования активностей:
- Поле ввода названия с автофокусом
- Выбор цвета из палитры
- Валидация ввода
- Кнопки сохранения/удаления

### 4.2 Расширение функциональности

#### Добавление нового экрана
1. Создайте композабл в соответствующей директории `ui/`
2. Добавьте экран в перечисление `AppScreen`
3. Обновите навигацию в `StopwatchApp.kt`

#### Добавление новой модели данных
1. Создайте data class в `data/model/`
2. Добавьте аннотацию `@Serializable`
3. Обновите соответствующий репозиторий
4. При необходимости добавьте миграцию данных

#### Изменение логики секундомера
1. Внесите изменения в `StopwatchState.kt`
2. Протестируйте все сценарии использования
3. Убедитесь в корректности сохранения состояния

### 4.3 Отладка и решение проблем

#### Распространенные проблемы и решения

**Проблема**: Material Icons не отображаются
**Решение**:
```kotlin
// Используйте текстовые иконки из TextIcons.kt
// Или добавьте зависимость: implementation(compose.materialIconsExtended)
```

**Проблема**: Ошибки парсинга цветов
**Решение**: Используйте `ColorParser.kt` вместо Android-специфичных методов

**Проблема**: Окно не меняет размер
**Решение**: Убедитесь в корректной работе `LaunchedEffect` в `StopwatchApp.kt`

#### Логирование и отладка
- Все ошибки сохраняются в консоль
- Данные автоматически сохраняются в JSON файлы
- Для отладки используйте стандартные средства IntelliJ IDEA
